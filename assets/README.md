# Screenshots

Declared in [`screenshots.json`](../screenshots.json) at the repository root — that
is the file storefronts (dsh-market, the awesome-dsh-plugin site) read to show the
plugin's detail view. Paths there are relative to the repository root, so keep the
two in sync if you rename anything here.

| File | Shows |
| --- | --- |
| `panel-session.png` | The detail panel for a single session: the total in CNY and USD, the current tier with a countdown, the peak / off-peak split, the rates in force, and the recount button with the number of calls it recovered. |
| `panel-team.png` | The same panel for an agent-team session: the total split into "of which this session" and "of which team members ×N", with the roster below and the Lead marked ★. |

Both were captured in a Chinese UI; the labels follow the app's language. Between
1 and 8 images are allowed, and PNG or JPEG are both fine. Keep personal data out
of frame, and prefer names that say what the picture shows rather than when it was
taken — a dated filename rots the moment it is re-shot.
